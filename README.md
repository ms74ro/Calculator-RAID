# Calculator RAID

<img src="icon.svg" alt="" width="96" align="right">

Calculator RAID pentru NAS, într-o singură pagină HTML, fără dependențe.

**Deschide online:** https://ms74ro.github.io/Calculator-RAID/

- Alegi numărul de bay-uri (2–24) și adaugi discuri de 1–32 TB, inclusiv de mărimi diferite.
- Vezi spațiul util, spațiul pentru protecție și spațiul neutilizat pentru JBOD, RAID 0, 1, 5, 6, 10, 50 și 60.
- Tabelul de comparație pune toate nivelurile RAID unul lângă altul: eficiență, discuri care pot ceda, viteză orientativă de citire și scriere.
- Avertismente pentru RAID 5 cu discuri mari, discuri de mărimi diferite și limitele ASUSTOR.
- Interfață în română și engleză, cu afișare luminoasă sau întunecată.

## Utilizare

Deschide `index.html` în browser. Funcționează și offline (fără internet se folosesc fonturile sistemului).

Pentru găzduire, copiază `index.html` (și opțional `icon.svg`) pe orice server web, de exemplu Nginx, Web Center pe ASUSTOR sau GitHub Pages.

Aplicația este oferită „ca atare”, fără nicio garanție.

# RAID Calculator (English)

A single-file, dependency-free RAID calculator for NAS units. Pick the number of bays, add drives (mixed sizes supported) and compare usable space, protection and fault tolerance across JBOD and RAID 0, 1, 5, 6, 10, 50 and 60. Romanian and English UI, light and dark mode.

Try it online: https://ms74ro.github.io/Calculator-RAID/

Or open `index.html` in a browser, or serve it from any web server.
